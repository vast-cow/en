The position of the pop-up notifications (toast notifications) that appear in the lower right corner of Windows cannot be changed in the standard settings of Windows 10 and 11.

However, you can move them to the upper right, upper left, lower left, or center of the screen by using **Windhawk, a free Windows customization tool**.

## **Setup Instructions**

1. Download and install from the [Windhawk official website](https://windhawk.net/?utm_source=chatgpt.com).
2. Launch Windhawk and open "Explore."
3. Search for `Customize Windows notifications placement`.
4. Click "Details" then "Install."
5. Change the display position of notifications in "Settings."
6. Save with "Save settings."

## **Display Position Examples**

| Display Position | Horizontal placement | Vertical placement |
| ------ | -------------------- | ------------------ |
| Upper Right | Right | Top |
| Upper Left | Left | Top |
| Lower Left | Left | Bottom |
| Upper Center | Center | Top |
| Lower Center | Center | Bottom |
| Lower Right (Standard) | Right | Bottom |

You can also fine-tune the distance from the edge of the screen and display notifications on a secondary monitor.

**Related Extension:** [Customize Windows notifications placement](https://windhawk.net/mods/notifications-placement?utm_source=chatgpt.com)

Note that Windhawk is an unofficial customization tool, so Windows updates may cause it to malfunction.

If you want to use only the standard features, you cannot change the position of the notifications, but you can hide the notification banner.
