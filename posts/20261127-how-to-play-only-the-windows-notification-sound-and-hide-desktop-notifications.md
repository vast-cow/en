In Windows, you can play only the notification sound and hide the pop-up (notification banner) in the bottom-right corner of the desktop.

## 1. How to configure it in Windows 11

1. Press `Windows key + I` to open "Settings."
2. Open "System" → "Notifications."
3. Click the app whose notifications you want to change.
4. Configure the settings as follows.

| Setting item | Setting value |
|---|---|
| Notifications | On |
| Show notification banners | **Off** |
| Show notifications in notification center | On |
| Play a sound when a notification arrives | **On** |

## 2. Behavior after configuration

| Notification type | Behavior |
|---|---|
| Notification sound | Plays |
| Desktop pop-up | Not displayed |
| Record in notification center | Remains |

You can check the notification center by pressing `Windows key + N`.

## 3. Notes

- Turn off "Do not disturb." If it is on, notification sounds may also be suppressed.
- If you want this behavior for all apps, you generally need to configure it for each app individually.
- If an app has its own notification features, also check the settings on the app side.

## 4. For Windows 10

From "Settings" → "System" → "Notifications & actions," select the target app and configure it in the same way.
